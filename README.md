# Getting Started with This App

## Requirements
Docker (https://docs.docker.com/get-docker/)
<br />
Node (https://nodejs.org/en/download/)
<br />
React (https://reactjs.org/)
<br />

<br />

Commands to follow:
<br />
#git clone <git@github.com:zep1994/Supervisor-management-notification-module.git>
<br />
#cd Supervisor-management-notification-module
<br />
#docker compose up
<br />
Note: I have build docker to handle most of the package installs so you should just have to run the compose command here.
<br />
Navigate to localhost:3000 in order to submit notifications
